# Security

A weakness in a contract — a capability that grants more than it says, a message an
implementation cannot safely refuse — is a security issue even before any code has it.
Report it privately through GitHub's **Security → Report a vulnerability** on this
repository. The organisation-wide policy is
[`.github/SECURITY.md`](https://github.com/EON-Extensible-Open-Network/.github/blob/main/SECURITY.md).

The core's threat model — what it defends against and what it does not — is in
[`eon-office-core/SECURITY.md`](https://github.com/EON-Extensible-Open-Network/eon-office-core/blob/main/SECURITY.md).
